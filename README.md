# Gregory Date

Консольная Java-программа, которая по указанному году выводит:
- информацию о том, является ли год високосным;
- список всех дней всех 12 месяцев этого года.

Реализовано в рамках тестового задания на позицию Java-разработчика (стажёр).

## Задача

Дан год (после 1600, григорианский календарь). Нужно построить и вывести
календарь этого года — список дней по месяцам с учётом того, что в
феврале високосного года 29 дней, а невисокосного — 28.

## Технологии

- Java 21
- Maven 3.x
- JUnit 5

## Структура проекта

```
src
├── main/java
│   ├── Main.java                  — точка входа
│   ├── CalendarService.java       — интерфейс сервиса
│   └── CalendarServiceImpl.java   — реализация логики
└── test/java
    └── CalendarServiceImplTest.java — юнит-тесты (JUnit 5)
```

## Сборка и запуск

Через Maven:

```bash
mvn clean compile
mvn exec:java -Dexec.mainClass="Main"
```

(если `mainClass` не задан в `pom.xml` через exec-maven-plugin, флаг
`-Dexec.mainClass` обязателен)

Либо вручную:

```bash
javac -d target/classes src/main/java/*.java
java -cp target/classes Main
```

## Использование

После запуска программа показывает меню и работает в бесконечном цикле, пока не введено `0`:

```
Меню:
1  - Вывести информацию о годе и всех его месяцах
2  - Узнать день недели по дате
0  - Выход
Введите команду: 1
Введите год: 1601

Год: 1601
Статус: Не високосный
Месяц: 0
Mon Jan 01 00:00:00 MSK 1601
Tue Jan 02 00:00:00 MSK 1601
...

Меню:
1  - Вывести информацию о годе и всех его месяцах
2  - Узнать день недели по дате
0  - Выход
Введите команду: 0
Выход из программы.
```

Если ввести не число, программа переспросит ввод, не завершаясь. Если ввести число, не совпадающее ни с одной командой, выводится сообщение о неизвестной команде и меню появляется снова.

## Запуск тестов

```bash
mvn test
```

Тесты проверяют:
- корректность определения високосного года (`isLeap`) для граничных
  случаев (кратность 4, 100, 400);
- текстовое представление результата (`printLeapInfo`);
- определение дня недели по дате (`getDayOfWeek`), включая перенос
  несуществующей даты (29 февраля в невисокосном году).
